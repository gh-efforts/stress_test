# stress_test
1.检测当前需要使用的nodes的状态；
2.修改测试的nodes；
3.检查与修改Common Command和Test Command中的参数，特别是路径参数；
4.填入需要测试的参数Params和Export Commands用"|"分割；
5.修改Log Timeout和Test Timeout；
6.点击"Start Testing"按钮开始进行压测；
7.在Start Service Logs查看nodes中启动服务的日志，Test Log中查看测试日志；
8.等待测试结果，Test Results中会显示出来，如果失败就在Failure Count中显示出来失败的参数。
